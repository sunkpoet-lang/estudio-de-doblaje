Página de presentación de **Estudio de Doblaje**, la app de escritorio para traductores de doblaje que genera time codes, traduce sin internet y sincroniza guiones. El sitio muestra qué hace la app, incluye las guías de uso y enlaza a las descargas.

- **Sitio:** <https://sunkpoet-lang.github.io/estudio-de-doblaje/>
- **Descargas de la app:** [estudio-de-doblaje-descargas](https://github.com/sunkpoet-lang/estudio-de-doblaje-descargas/releases/latest)

## Qué contiene

| Archivo | Para qué sirve |
|---|---|
| `index.html` | La página completa (HTML, CSS y JavaScript en un solo archivo) |
| `guia.pdf` y `guide_en.pdf` | Guía de uso en español y en inglés |
| `promo.mp4` | Video de presentación |
| `*.jpg` y `img/` | Capturas de la app y el póster de la página |

La página está en español, inglés, portugués y francés, y se publica sin precios.

## Verla en tu equipo

No necesita compilar nada. Abre `index.html` en el navegador, o sirve la carpeta con cualquier servidor estático:

```bash
python3 -m http.server 8000
```

y entra a <http://localhost:8000>.

## Publicación

El sitio se publica con GitHub Pages desde la rama `main`, con `index.html` en la raíz. Cada cambio que se sube a `main` se publica solo, así que conviene revisar la página en local antes de subirlo.
